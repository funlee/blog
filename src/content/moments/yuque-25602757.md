[CSS3实现0.5px边框](https://segmentfault.com/a/1190000020640155):

1. border + border-image + 线性渐变linear-gradient；

1. 定位 + 伪元素 + background + 线性渐变linear-gradient；

1. 定位 + 伪元素 + transfrom缩放（scale）

```css
.border {
 width: 200px;
 height: 200px;
 margin: 0 auto;
 position: relative;
}
 .border::before {
  content: " ";
  position: absolute;
  top: 0;
  left: 0;
  width: 200%;
  height: calc(200% - 2px);
  border: 1px solid red;
  transform-origin: 0 0;
 transform: scale(0.5);
}
```
