移动端要隐藏掉影响美观的滚动条主要涉及一个伪元素-webkit-scrollbar

实现代码如下：

```css
.scroll-view {
  height: 100%;
  overflow-y: scroll;
  overflow-x: hidden;
  -webkit-overflow-scrolling: touch;
}
 .scroll-view::-webkit-scrollbar{
  display: none;
}
```
