> **迁移校注（2026-10-12）：** 以下保留 2016 年的学习记录和原始代码。原方案把密码写入 Cookie，这一做法不应继续使用，内部系统也不例外。登录应由服务端校验凭据并签发会话标识，通过 HTTPS 传输，结合 `HttpOnly`、`Secure` 和合适的 `SameSite` 属性保护会话；退出时还需使服务端会话失效。参见 [MDN：HTTP Cookie](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Cookies)和 [OWASP：会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。
>
> 原文“MD5 加密”的表述不准确：MD5 是散列算法，不能替代上述会话保护。下面三个 Cookie 方法也是原始对象成员片段，不能直接当成独立函数运行；其中 `escape` 与 `decodeURI` 编解码不配套，读取正则的 `(^|)` 会误匹配名称后缀，删除时的 `document.write` 可能覆盖页面。修正时应使用配套的 `encodeURIComponent` / `decodeURIComponent`、按完整名称解析 Cookie、保持相同的 Path/Domain，并移除 `document.write`。这些问题在此单列说明，未将原项目改写为新的实现。

想想很长一段时间以来，都在说自己不会写cookie，不会写cookie，不会写cookie，自己也说腻了，别人也听腻，可就是没去了解学习一下cookie到底是个什么玩意。上周做了一个简单的项目管理系统，正好有个登录功能，借此机会，搞了一下cookie，也碰了一下登录功能，感觉还不错。

先来说说本次项目登录功能的实现点吧：

1. 登录功能具备输入密码后敲“回车”直接登录；

2. 登录成功会有一个写入cookie的操作，写入内容包括：用户名、密码和邮箱；

3. 登录成功页面会跳转到“项目总览”页面；

4. 所有页面（非登录页）初始加载会验证本机是否有登录信息cookie，没有，则会跳转到登录页面；有，则会验证cookie中用户名和密码是否正确，正确则保持当前页面，错误，会删除cookie并跳转到登录页面；

5. 如果当前页面是登录页面，初始化会检测是否有cookie，有，则会自动填充用户名，密码需要手动输入；没有，则需要用户自己输入用户名和密码进行登录；

6. 退出登录是删除cookie并返回到登录页。

PS：本次所做的系统是给内部使用的，所以没有做密码的MD5加密；没有注册功能，也就没有做用户名和密码的正则校验。

先来看看JS对于cookie的操作：

## 设置cookie：

```js
setCookie:function(name,value){
            var Days = 30;
            var exp = new Date();
            exp.setTime(exp.getTime() + Days * 24 * 60 * 60 * 1000);
            document.cookie = name + "=" + escape(value) + ";expires=" + exp.toGMTString();
        }

```

## 获取cookie：

```js
getCookie:function(name) { 
            if(!name) return '';

            var reg = new RegExp('(^|)' + name + '=([^;]*)(;|$)');
            var arr = document.cookie.match(reg);

            if(arr) {
                return decodeURI(arr[2])
            }
            return '';
        }

```

## 删除cookie：

```js
delCookie:function(name){
            var exp = new Date();
            exp.setTime(exp.getTime() - 1);
            var cval=this.getCookie(name);
            if(cval!=null) document.cookie= name + "="+cval+";expires="+exp.toGMTString();
            document.write(document.cookie);
        }

```

最后附上一个简单的登录功能

## 登录功能：

```js
$(".login-btn").on("click", function () {

                var username = $("#username").val();
                var password = $("#password").val();

                if (username == '') {
                    alert("请输入用户名");
                } else if (password == '') {
                    alert("请输入密码");
                } else {

                    $.ajax({
                        type: "POST",
                        url: window.utils.login,
                        headers: {
                            'Content-type': 'application/json;charset=UTF-8'
                        },
                        data: JSON.stringify({
                            'username': username,
                            'password': password
                        }),
                        dataType: 'json',
                        async: false,
                        success: function (data) {
                            if (data.status == "success") {
                                console.log("登录成功");
                                var userInfo = data.username + '|' + data.email + '|' + password;
                                window.edtCookie.setCookie('userInfo', userInfo);
                                console.log("写入cookie成功")
                               window.location.href = 'HTML/html/project.html';//登录成功页面跳转
                            } else {
                                alert("帐号或密码错误");
                            }
                        },
                        error: function () {
                            alert("请求错误！！");
                        }
                    });
                }
            });

```
