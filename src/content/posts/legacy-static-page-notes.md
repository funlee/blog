## 一、图层切图

以前都是在一个PSD文件上拉很多辅助线，作为一个转行的新手，看到大家都不用这样切图，表示自己很无知，呵呵哒。尤其是对于`icon`小图标类，按照以前的切图，那个误差简直不能忍，当是圆角之类，表示很揪心。自从学会了图层切图，嘛嘛再也不用担心我切图不精准了，保存背景透明格式，记得选择存储为web所用格式，选择PNG格式，值得一提的是：从PS CC版本开始，可以支持脚本切图，很强大，很牛逼，感兴趣值得试试!

## 二、CSS样式做到易复用

CSS书写顺序**遵循先布局后内容的顺序**，比如优先布局，我们知道布局属性有 display, float, overflow 等等；内容次之，比如 color, font, text-align 之类。CSS样式命名要做到**不依据表现形式来命名，应该根据内容或者功能来命名**，这样才能更好的实现复用，推荐一种命名方法：

- g-全局通用样式命名，前缀g全称为global，一旦修改将影响全站样式，如：g-mod
- m-模块命名方式，如：m-detail
- ui-组件命名方式，如：ui-selector
- js- 所有用于纯交互的命名，不涉及任何样式规则，如：js-switch

## 三、响应式布局尺寸问题

移动端页面书写的最大特点莫过于要做点响应式布局，也就是要兼容各种不同的屏幕大小，在自己没写移动端页面之前，总觉得很复杂，那是对于响应式布局没有大多的了解，真正自己实际去写了一些页面过后，实际上也没那么复杂。移动端浏览器不像PC端的浏览器存在那么多的兼容问题，书写的时候，HTML5和CSS3是可以直接使用的，IE6的问题在移动端是没有必要考虑的，从这个层面上来说，移动端页面的书写要比PC端轻松的多。在写响应式页面的时候，重点是字体大小、图片大小、长宽高的确定，使用Firefox，利用`Ctrl+M`进行移动端页面调试，宽度尽量使用百分比。以下是一点点小心得：

- 使用HBuilder编辑器，进入边看边改模式，可以非常方便的进行调试，安装手机助手，还可以支持用自己手机进行页面预览，感兴趣可以深入研究HBuilder的强大功能。
- CSS 的百分比宽度通常以包含块的宽度为基准；在普通文档流中，包含块通常由父级块容器形成，并不是逐层寻找显式设置宽度的祖先。通过一个`div>ul>li`的结构进行验证。
- 部分浏览器的最小字体设置可能限制小字号显示，例如当时常见的 12 像素限制；这不是 CSS 的统一规则。
- 对于小图片，应该进行雪碧图制作，遵循同样的请求量，减少请求次数。

## 四、水平居中和垂直居中

- 如果被设置元素为文本、图片等行内元素时，水平居中是通过给父元素设置`text-align:center `来实现的。
- 当被设置元素为块状元素时用 `text-align:center` 就不起作用了，这时要分两种情况：定宽块状元素和不定宽块状元素。满足定宽和块状两个条件的元素是可以通过设置“左右`margin`”值为“auto”来实现居中的；不定宽度的块状元素有三种方法居中：加入 table 标签、设置 `display:inline` 方法、设置 `position:relative `和 `left:50%;`
- 父元素高度确定的单行文本的竖直居中的方法是通过设置父元素的 `height 和 line-height` 高度一致来实现的。
