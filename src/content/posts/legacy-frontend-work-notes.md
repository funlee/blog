记录一些最近半个月以来遇到的一些问题以及解决方法，可能大部分在经验人士看来简直都是一些小儿科，对我，确实实在在是第一次见识，就这样开始把！

1、对于公用的头部和底部使用`<!--#include virtual="xxx.html"-->`。这样的话就只需写一次，省了每个页面都去复制粘贴一遍，但本地访问是无效的，需要通过服务器端访问才能看到效果。

2、利用`ul>li>a`结构制作水平导航，最初是让li左浮动，用的很长一段时间后发现对li设置`display:inline-block`依然能够实现水平导航，但是本周写PC页面发现在IE7下就出现问题了，所以，还是老老实实用左浮动把，手机页面倒是可以用用。

3、近来对于弹出框的效果全部使用的是`layer`这个插件，当遇到多个页面的弹出层是一样的时候，为了复用，我们的做法是把弹出层写成单独的一个HTML片段，然后通过Ajax加载，这样做会出现的问题是：原先直接绑定到已有元素上的事件，不会自动绑定到 Ajax 新插入的元素。可以使用事件委托，或在插入 HTML 后绑定事件；外部 JS 文件本身并不会因此失效。另一种办法是不通过 Ajax 加载，而是使用当前页面中已有的内容。下面分别是两种加载方式的代码：

Ajax加载layer片段：

```javascript
$("#paybill").click(function () {
  $.ajax({
    type: "get",
    cache: true,
    timeout: 4000,
    url: "paybill.html",
    dataType: "html",
    success: function (data) {
      layer.open({
        type: 1,
        title: "",
        area: ["440px"],
        content: data
      });
    },
    error: function () {
      alert("出错！！");
    }
  });
});
```

本页面加载：

```javascript
$(".paybill").each(function () {
  $(this).click(function () {
    layer.open({
      type: 1,
      title: "",
      area: ["440px", "600px"],
      content: $(".pay-bill")
    });
  });
});
```

第一次使用上面的本页面加载，遇到 `$(".pay-bill")`这个DOM结构会显示在当前页面上，这显然不是我们想看到的，我们的目的是让这个DOM以弹出层的形式显示，所以我的做法是在外层套一个div，对这个div指定如下样式

```css
height: 0;
width: 0;
overflow: hidden;
```

4、对于下拉列表，默认用法都是利用`select>option`这样的结构，但在要兼容IE7的项目中，就会发现，真丑，修改了样式还不兼容，在本周的项目中，对于下拉列表是通过自定义列表和js控制来实现的，参考如下链接：[点击查看页面中的下拉列表](http://demo.funlee.cn/012/adminManage/dishes-mng.html)，这样兼容性比较好，也比较容易实现设计稿的样式。

5、实现一个页面中两个或者两个以上区域可以出现滚动效果，例如美团的页面：

自然想到的是使用`iframe`框架，HTML5 并没有废弃 iframe（废弃的是 frame 和 frameset），自己亲手使用了一下，发现并不好用，而且框架的滚动条显示出来，真的丑到没朋友。最后的解决办法是给滑动区域外层套一个div，外层div设置样式：position:fixed;内层div设置`position: absolute;overflow:auto;`这样就能实现区域内滚动的效果，其实实现可以滚动还和高度有关，美团页面的做法是把高度设置的比整个竖向导航高度还要小，自然可以出现滚动条，我们项目中要实现的是：当导航高度大于用户手机屏幕高度的时候就出现滚动条，没有则不需要滚动条，因为一屏可以看完，所以我们的做法是把内层div的高度设置为屏幕的高度，用js实现。

6、关于锚点定位，锚点的惯用用法这里不用多说，本周项目中遇到的是头部使用了定位`fixed`，所以再使用锚点的话，被锚点的地方会钻到头部的下面去，因为被锚点的地方默认是top：0；为了解决这个问题，最后的做法是利用`jq的eq（index）`将导航列项和对应的被锚点遍依次历，然后改变锚点的top值来实现。

7、js隐式类型的实际应用：减号能实现Number类型的转化，但是用加号的时候就要小心了，必须得先进行类型转换，不然就是字符串拼接，这个时候，你需要使用这个函数：`parseInt()`

8、在进行统计计算单价的时候，设计稿上往往是保留了两位小数，在计算过程中为了避免上述第七点中的问题，`parseInt()`函数默认是没有保留小数的，这个时候，你需要使用` toFixed(n)`函数
例：

```javascript
var s = "29.3231565";
s = parseFloat(s).toFixed(1); //保留一位小数
```

要记住的是`toFixed(n)`返回的是字符串类型，而非Number类型。

9、说到第八点我就又想起一个东西，在jquery中判断一个数据是否存在一个数组中，使用的是：

```javascript
$.inArray("js", arr);
```

返回的是所要判断的数据在数组的位置，默认起始值是0，如果不存在，则返回-1；这是一个本周走过的坑，我居然以为返回的是`true或false`。
